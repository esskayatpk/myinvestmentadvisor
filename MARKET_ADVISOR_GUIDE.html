AI-powered investment research & portfolio intelligence tool — Complete Guide & Setup

What Is Market Advisor?

Market Advisor is a standalone React web application that combines real-time market data, technical analysis computed entirely in your browser, and an AI advisor (powered by Anthropic Claude via your existing Supabase project) to help you research, monitor, and strategise your investment portfolio.

It was built specifically for a medium-to-high risk investor starting from a ~$500K portfolio with a goal of reaching $1,000,000. It covers:

  • ETF, stock, and fund analysis — mid-cap & small-cap focus
  • Forex opportunities — 10 curated currency pairs including majors, minors, and exotics
  • 5-Pillar technical signals — Trend, Location, Volume, Risk:Reward & Market Structure; scored across 7 checklist criteria and gated by a "No Checklist, No Trade" rule
  • AI portfolio review — Claude analyses your entire portfolio and produces structured, actionable advice
  • OCR portfolio upload — drop a brokerage screenshot and the app reads your holdings automatically
  • Options Trading Playbook — 7-strategy framework for high-probability options trades with interactive calculators (P&L, scale-out targets, flow confirmation checker, and the Golden Rule scorecard)
  • $1M goal tracker — visual progress bar and compound-growth projections
ℹ️ Privacy first. All technical analysis is computed locally in your browser using JavaScript — no price data or portfolio details are sent to any server unless you explicitly click "Generate AI Analysis". API keys are stored in your browser's localStorage only.

Supabase Setup

1. Environment Config

You can reuse your existing Sol POS Supabase project — no new database tables are required. Market Advisor only uses the Supabase Edge Functions runtime.

Find your values at app.supabase.com → Project Settings → API:

  • VITE_SUPABASE_URL = Project URL (e.g. https://abcdefghij.supabase.co)
  • VITE_SUPABASE_ANON_KEY = anon / public key

2. Deploy the AI Edge Function

The edge function lives at supabase/functions/market-advisor/index.ts. Deploy it with the Supabase CLI:

1
Install Supabase CLI (if not already installed)
npm install -g supabase
2
Log in to your Supabase account
supabase login

This opens a browser window for OAuth. Paste your access token if prompted.

3
Link your project (replace with your real project ref)
cd c:\sk\sol\investment-advisor
supabase link --project-ref abcdefghijklmnop

Your project ref is the 20-character string in your Supabase project URL.

4
Deploy the market-advisor function
supabase functions deploy market-advisor --project-ref abcdefghijklmnop

Output should say Deployed Function market-advisor with a URL.

3. Set the ANTHROPIC_API_KEY Secret

The edge function calls Claude. Set your Anthropic API key as a Supabase secret (it is stored encrypted — never exposed to clients):

supabase secrets set ANTHROPIC_API_KEY=sk-ant-api03-YOUR_KEY_HERE --project-ref abcdefghijklmnop

Or via the dashboard: Supabase → Edge Functions → Secrets → Add Secret.

If you already set ANTHROPIC_API_KEY for the Sol POS AI Chat function, it is already available — no action needed.

Get an Anthropic API key at console.anthropic.com. The AI Advisor uses claude-opus-4-5. Each full analysis uses ~1,000–2,500 output tokens (roughly $0.02–0.08 per analysis on the standard tier).

✅ Verification: After setup, go to the AI Advisor tab and click Generate Analysis. If you see a portfolio score and recommendations appear within ~20 seconds, everything is wired up correctly.

Upload Tab — Portfolio OCR

This is the starting point. Drop a screenshot from your brokerage app (Fidelity, Schwab, TD Ameritrade, Robinhood, E*TRADE, etc.) and the app will attempt to extract your holdings automatically.

How it works

  1. You drop or click to upload any PNG/JPG screenshot of your portfolio
  2. Tesseract.js (an OCR engine compiled to WebAssembly) runs entirely in your browser — the image never leaves your device
  3. The extracted text is parsed by a custom ticker-detection algorithm that identifies uppercase 1–5 character strings and filters out common English words
  4. Dollar amounts on the same line are matched to each ticker
  5. You review and edit the results in an inline table before confirming

OCR tips for best results

  • Use a light-background screenshot — dark broker UIs with low contrast reduce accuracy
  • Crop tightly to the holdings table — remove headers, footers, and sidebar navigation
  • If OCR fails, simply type holdings manually in the editable table — it has an Add row button
  • After confirming, go to the Portfolio tab and click Live Prices to fill in current prices and names

Manual editing

Every field is editable after OCR. You can:

  • Correct mis-read tickers (common: O → 0, I → 1, etc.)
  • Adjust market values
  • Change asset class (ETF, stock, fund, bond, forex, crypto)
  • Set the cap category (mid-cap, small-cap, large-cap, international, etc.)
  • Add rows that OCR missed
  • Delete false-positive rows

At the bottom, set your current portfolio value, goal value (default $1,000,000), and any uninvested cash.

ℹ️ Your portfolio is saved to localStorage as soon as you click Confirm Portfolio. It persists across browser sessions — you do not need to re-upload every time.

The 5-Pillar Scoring Framework

📌 Key principle: “The best traders don’t look for more trades. They look for better trades.” Only take trades where the majority of checklist items pass.

Pillar 1 — Trend  up to ±32 pts

First question: Is the stock in an uptrend? Never fight the trend — it is your biggest edge. Look for Higher Highs + Higher Lows and price above the 21 EMA.

🚫 Hard rule — No longs in a downtrend. When Pillar 1 detects a confirmed downtrend, the signal engine automatically caps any bullish raw score at WATCH. A BUY or STRONG BUY cannot be issued regardless of the other pillar scores. Plan your trade after the trend reclaims the 21 EMA.

Higher Highs + Higher Lows (20-bar window)Confirmed uptrend structure+12
Lower Highs + Lower Lows (20-bar window)Confirmed downtrend structure−12
Price above EMA 21Trend intact — long bias valid+10
Price below EMA 21Trend broken — avoid new longs−10
Price above SMA 200Long-term uptrend intact+6
Price below SMA 200Long-term downtrend−6
Price > SMA 50 > SMA 200Full bull alignment+4
Price < SMA 50 < SMA 200Full bear alignment−4

Pillar 2 — Location  up to ±33 pts

Where are you buying? Three valid buy locations: near 21 EMA, near support (lower BB), or retesting a prior breakout level as support. The closer you are to value, the lower your risk. Random entries far from structure have terrible risk-reward.

💡 Breakout retest detection: The engine looks back 35 bars to find the prior swing high, then checks whether any of the last 5 bars closed above it (breakout confirmed). If yes, and the current price is within 3–5% of that level from above, the “at resistance” penalty is suppressed and the retest bonus (+15) is awarded instead.

Pillar 3 — Volume  up to ±18 pts

Volume tells the truth. High volume on breakouts = institutions buying. Low volume on pullbacks = weak selling pressure (opportunity). High volume on down-days = distribution.

ConditionSignalScore

Above-average volume on down-daysDistribution / institutional selling−15

Pillar 4 — Risk : Reward  up to ±15 pts

Before entering, ask: “If I’m wrong, how much can I lose?” Protect capital first. Profits come later. Never risk $100 to make $100.

  • Stop-loss = Entry price − (ATR 14 × 1.5)
  • Target price = Entry price + (ATR 14 × 3.0)
  • R:R ratio = reward ÷ risk = (target − entry) ÷ (entry − stop)

1 : 2 to 1 : 3Acceptable — minimum standard+8
< 1 : 2Below minimum — skip this trade ✗−12

Strong stocks show: Consolidation → Tight Price Action → Expansion.
Weak stocks show: Random moves, high volatility, no structure.

RSI and MACD act as confirmation on top of the 5 structural pillars, not as the primary signal.

📖 What Is Swing Trading? (Plain English)

When you buy a stock and hold it for years, that is investing. When you buy and sell on the same day, that is day trading. Swing trading sits in the middle — you hold a position for a few days to a few weeks, trying to capture one meaningful price move.

The idea is simple: stock prices do not move in straight lines. They rise, pause, dip a little, then rise again. Swing traders try to:

  1. Buy during the dip (the "pullback") when the stock is still in an uptrend
  2. Hold while the price continues higher
  3. Sell at a planned target to lock in the gain

You do not need to watch the screen all day. You check your open positions in the morning and again in the evening — about 10–15 minutes per day.

✅ What swing trading IS
Buying with a plan. Defined entry, stop loss, and target. Holding 2–10 days. Risking a small, fixed amount. Following rules.
❌ What it is NOT
Guessing. Holding forever hoping it recovers. Moving your stop loss lower. Chasing a stock that has already moved 10%.

💸 When and How to Sell

There are three reasons to sell a swing trade, and three reasons only. Anything else is emotion, not strategy.

Reason 1: Stop Loss Hit (the trade went against you)

🛑 If the stop is hit, sell immediately. No exceptions. No "let me wait and see if it bounces."

The app's Open Position Monitor will show a red 🛑 STOP HIT card with an Exit Now button. It also shows the exact dollar loss. Here is what you do:

1
Your broker already sold automatically (if you set the stop order)

Because you set a stop order at your broker in Step D above, your shares were already sold the moment price hit $412. Your broker handled it automatically.

2
Log the exit in the Investment Advisor journal

In the Trade Journal, find the MSFT trade. In the "Exit" column, enter the price your broker sold at (e.g., $411.80). Click the checkmark. The journal will calculate your R-multiple automatically: −1.0R = a standard 1-unit loss.

3
Click "+ Log a Loss" in the Risk Guard

The Risk Guard tracks daily and weekly loss limits. After a losing trade, click the + Log a Loss button. If you hit 2 losses in one day, the app shows a red STOP banner — stop trading for the rest of that day.

Reason 2: Target Reached (the trade went in your favour)

The app will show a green ✅ TAKE PROFITS — TARGET card with the dollar gain amount. Follow this process:

1
Sell 50% at the 2R target

Do not sell everything at once. At the 2R target ($436), sell 31 shares (half of 62). This locks in $496 gain on those 31 shares. The other 31 shares continue to run.

2
Move your stop to breakeven on the remaining shares

At your broker, update your stop loss order from $412 to $420 (your entry). Now the remaining 31 shares cannot result in a loss — worst case you exit at $0 gain.

3
Let the rest run to the 3R target ($444)

If MSFT continues to $444, sell the remaining 31 shares. Total gain: ($436−$420) × 31 + ($444−$420) × 31 = $496 + $744 = $1,240 total on a $496 risk.

4
Log both exits in the journal

In the journal, enter your average exit price. The app will calculate your final R-multiple (e.g., +2.5R).

Reason 3: Strategy Invalidated (the setup no longer applies)

Sometimes a trade hasn't hit the stop OR the target, but the reason you entered no longer exists. Exit if:

  • Price breaks below the 20-EMA and closes there for 2 consecutive days (trend broken)
  • A major negative news event hits the stock (earnings miss, fraud allegation, sector collapse)
  • The trade has been open for more than 15 trading days with no progress toward the target (time stop)

In these cases, close the trade at market price. Staying in a broken setup hoping for a recovery is not swing trading — it's gambling.

What Are Options? (Plain English)

Forget the jargon for a moment. Here is the simplest way to think about options:

Buying a stock = you own a piece of the company.
Buying an option = you pay for the right (not the obligation) to buy or sell that stock at a fixed price, before a fixed date.

That right costs money — called the premium. Think of it like booking a hotel room that you can cancel. You pay a small deposit now. If the trip goes ahead, great — you use the room at the price you locked in. If you cancel, you lose only the deposit. You do not owe the full room cost.

💡 Why trade options instead of stocks? Leverage. A $500 option can control 100 shares of a $200 stock ($20,000 worth). If the stock rises 10%, your option might rise 50–100%. But if the stock goes the wrong way, you lose your $500 — not $20,000.

Strategy 1 — Scale Out of Winners 🏆

The problem beginners make: They hold an option that doubled and do nothing, hoping for a triple. Then the stock pulls back, the option decays, and they end up with less than they started.

The solution: Sell in pieces as the option gains value. Don't try to pick the exact top. Lock in profits progressively.

When option is up...Sell this muchWhy
+20% to +30%2 contracts (half position)Locks in early gains, removes most emotional pressure
+50% to +60%2 more contractsReduces risk further — the remaining contracts are now effectively free
+100% or moreLast 1–2 contractsThe “home run” exit — you rode the full move with risk-free contracts
✅ Key principle: “Small wins pay for the right to hold big winners.” Once you've sold half and recovered your cost, the remaining contracts are playing with house money.

Example: You buy 4 call contracts for $250 each = $1,000 total cost.
→ Option rises 30%: sell 2 contracts at $325 each = $650 back.
→ Option rises 55%: sell 2 more at $387 each = $774 back.
→ Total recovered: $1,424 on a $1,000 outlay. Any further gain is pure profit.

The Scale-Out Calculator in the app does this maths for you — enter your premium and contract count to see exact exit prices.

Strategy 2 — Expiration is Insurance, Not a Deadline 🛡️

Think of an option like a car insurance policy. You buy 12 months of coverage. You don't have to make a claim on month 11 — but you want enough time for something to happen. Buying a 7-day option and expecting a big move is like buying insurance for only 7 days and hoping you need it.

Why longer is better:

  • More time for your thesis to play out — the stock has room to make the move
  • Theta decay (the ice-cube melt) is slower when there's more time remaining — you don't lose value as fast each day
  • You have flexibility to roll the trade, adjust, or exit calmly without panic
  • Short-term options (weekly “lotteries”) decay at warp speed in the last 7 days

Strategy 3 — Avoid the “Lottery Ticket” Mistake 🎰

The temptation: A $0.10 option looks like a bargain. “If it hits, I'm rich!” This is how most beginners blow up their options account.

The reality: Far out-of-the-money (OTM) options require all four of these to happen simultaneously:

  1. The stock must move — a lot
  2. The stock must move fast
  3. Implied volatility must cooperate
  4. You must still have time remaining

Each factor alone is unlikely. All four together? Near impossible most of the time.

The solution — buy probability, not cheapness:

Strike typeDelta rangeWhat it meansVerdict
Far OTM0.05 – 0.20Stock needs to move 10–20%+ just to break even. Very low probability.❌ Lottery ticket — avoid
OTM0.20 – 0.40Cheaper but still speculative. Stock needs a meaningful move.⚠️ Speculative — size small
ATM0.40 – 0.60Strike ≈ current price. Reasonable probability. This is the focus zone.✅ Best balance of cost and probability

💡 Delta shortcut: Delta also approximates the probability that the option finishes in-the-money at expiry. A delta of 0.50 (ATM) means roughly a 50% chance of profit at expiry. A far OTM option with delta 0.05 has only a ~5% chance — but costs only $50. Paying $50 for a 5% shot is a casino, not investing.

Strategy 4 — The Rolling Strategy 🔄

Rolling means closing your current option and opening a new one at the same time — using the profit from the first trade to fund the next one. You stay in the trend without risking your original capital again.

Analogy: Imagine you win $300 at a poker table. Instead of cashing out completely, you buy into a bigger game with your winnings. Your original $200 buy-in is safe in your pocket. You're playing with house money.

📌 Key rule: If the new position fails, the original trade already paid for it. You cannot lose your initial investment.
Option typeHow to rollWhy
📈 Calls (bullish)Close current call → open a new call at a higher strike and further expiry dateYou follow the trend upward. The new higher strike locks in your profit from the first trade while maintaining upside exposure.
📉 Puts (bearish)Close current put → open a new put at a lower strike and further expiry dateYou follow the trend downward. Each roll adds more DTE so theta decay doesn't eat your thesis alive.

Example of rolling a call:

  1. Buy a $450 call for $3.00 ($300 total cost)
  2. Stock rises to $465. Your call is worth $5.50.
  3. Roll: Sell the $450 call for $5.50 (+$250 profit) → Buy a $465 call for $3.20
  4. Your net cost for the new $465 call: $3.20 − $2.50 profit = $0.70 net cost
  5. You're now in the next trade for almost nothing — house money is doing the work

Strategy 5 — Use Flow as Confirmation 🌊

What is options flow? When large hedge funds, institutions, or “smart money” make big options bets, those trades appear on the market tape. They can't fully hide. Flow analysis is reading those large prints to understand what the big players are positioning for.

Important: Flow shows you intent. It doesn't tell you if they're right. You still need your chart levels and trend to confirm before acting.

Strategy 6 — The Golden Rule: Flow + Levels + Trend 🎯

This is the most important strategy. Never act on just one signal. The highest-probability options trades require all three pillars aligned:

PillarWhat it tells youExample signals
🌊 FlowConviction — what the big players are doingCalls lifting the ask, volume > OI, sweeps, rising IV
📍 LevelsLocation — is the stock at a key price level?Near support, VWAP, prior highs/lows, 21 EMA
📈 TrendDirection — is the stock trending the right way?Higher highs and lows, price above 21 EMA, sector trending with trade
Flow gives you intention. The chart and levels solidify the idea. — woofstreets.com

Why all three matter:

  • Flow alone is dangerous — big players are sometimes early or wrong. Many “unusual options activity” alerts lead to losses if you blindly follow them.
  • Chart levels alone miss the catalyst — you might sit at support for weeks with no move.
  • Trend alone doesn't tell you when to enter — you could buy at the worst location in a good trend.
  • All three together = the big players are betting on a move, the stock is at the right price level, and the trend supports the direction. That's your highest-probability setup.

ATR — Average True Range & Stop-Loss Sizing

ATR measures average daily price volatility over 14 periods. It is used to set intelligent stop-losses that account for normal market noise.

Rule of thumb for stop-losses:

  • Conservative stop: Entry price − (ATR × 1.5)
  • Moderate stop: Entry price − (ATR × 2.0)
  • Wide stop (trend following): Entry price − (ATR × 3.0)
Example: If VTI is at $260 and its ATR-14 is $4.20, a 1.5× stop would be at $260 − $6.30 = $253.70. This gives the position room to breathe through normal daily swings without triggering a stop on noise.

Troubleshooting

Quotes show "—" / no prices loading

  • In production: Yahoo Finance proxy is dev-only. Add a production proxy or use Polygon.io — enter your Polygon key in Settings.
  • In dev: Ensure npm run dev is running (proxy only works via Vite). Check the browser console for CORS errors.

OCR extracted the wrong tickers

  • Edit any row in the table directly — click the ticker field and type the correct symbol
  • Try a lighter/cleaner screenshot with better contrast
  • Use the Show raw OCR text toggle to see exactly what the engine read

AI Advisor returns an error

  • Verify VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY are set in your .env
  • Verify the edge function is deployed: supabase functions list --project-ref YOUR_REF
  • Verify the Anthropic API key secret: supabase secrets list --project-ref YOUR_REF
  • Check edge function logs: Supabase dashboard → Edge Functions → market-advisor → Logs

Forex rates show 0.00000

  • ExchangeRate-API may be temporarily unavailable. The app caches rates for 1 hour — click Refresh to retry
  • XAU/USD (Gold) may not always be included in free ExchangeRate-API responses. The value will show as 0 in that case; use Yahoo Finance directly for gold prices

Technical indicators say "not enough data"

  • SMA 200 requires at least 200 trading days of history (~10 months). If a ticker is new (<1 year old) the 200-day SMA will not display
  • Try fetching with a longer range: currently set to 1y. For very new ETFs use Polygon with a 2y range

Build error: "Cannot find module vite/client"

Ensure src/vite-env.d.ts exists with content /// <reference types="vite/client" /> — this file provides import.meta.env types.

Yahoo Finance in production / CORS

The Vite dev server proxies /api/yahoo/* to query1.finance.yahoo.com. In production you need to handle this via a server-side route. The simplest approach is an additional Supabase edge function that fetches from Yahoo Finance server-side and returns the data to the browser.

7TrendThe general direction the market is moving — up (bullish), down (bearish), or sideways (neutral). "The trend is your friend until it bends."💡 Example: NVDA was in a powerful uptrend throughout 2023, gaining 250%+ on AI chip demand. Traders who bought every pullback in the trend made far more than those who fought it.📈 Market DirectionInvestopedia NVDA Chart
8UptrendA series of higher highs and higher lows — the market is climbing in a staircase pattern. Each peak and each trough is above the last.💡 Example: Apple (AAPL) from 2016–2021 showed textbook uptrend structure: every earnings dip created a higher low, every rally set a new all-time high. Perfect staircase up for 5 years.📈 Market DirectionInvestopedia AAPL Chart
9DowntrendA series of lower highs and lower lows — the market is falling in a staircase pattern. Shorting or staying in cash is the correct strategy.💡 Example: META crashed from $384 (Sep 2021) to $88 (Nov 2022) — a 77% drop. Every bounce was lower than the previous one. "Catching the falling knife" cost many traders heavily.📈 Market DirectionInvestopedia META History
10SidewaysPrice moves within a horizontal range, bouncing between support and resistance. Also called consolidation or chop. Trend-following strategies perform poorly in sideways markets.💡 Example: Gold (XAU/USD) traded in a tight $1,800–$2,050 range for 18 months (2022–2023) before finally breaking out to new ATHs above $2,400 in 2024.📈 Market DirectionInvestopedia Gold Chart
11BreakoutPrice breaks above resistance (or below support) with conviction, often signaling the start of a new trend leg. Should be confirmed with above-average volume.💡 Example: NVDA broke above $400 resistance in May 2023 on massive volume after earnings — triggering a 50%+ rally in weeks. The breakout, combined with 3× average volume, was a textbook high-conviction entry.📈 Market DirectionInvestopedia NVDA Chart
12PullbackA temporary retracement against the main trend. In an uptrend, price dips briefly before continuing higher — used as a buying opportunity by trend traders.💡 Example: SPY pulled back 5% from $520 to $495 in April 2024 while the overall uptrend remained intact. Traders who bought that pullback at the 21 EMA were rewarded as the market rallied to new highs within weeks.📈 Market DirectionInvestopedia SPY Chart
13RetestAfter a breakout, price returns to touch the broken level (old resistance now acts as new support). A successful retest confirms the breakout is genuine.💡 Example: AAPL broke above $180 resistance in mid-2023, pulled back to retest $180 as support, held it on high volume, then rallied to $220+. The retest gave a second entry for those who missed the initial breakout.📐 Price StructureInvestopedia Babypips
14CandlestickA chart bar showing price for one time period. The body = open-to-close range. The wicks = high and low extremes reached. Japanese traders invented this in the 1700s.💡 Example: A green daily candle: Open $220, Low $215 (wick down), Close $232, High $235 (wick up). The large green body shows buyers dominated all day. The small upper wick means sellers tried at $235 but failed.🕯️ PatternsInvestopedia StockCharts
15DojiA candlestick where open and close are nearly equal — little or no body. Signals indecision between buyers and sellers. Can signal a reversal, especially after a strong trend.💡 Example: SPY printed a textbook doji on October 13, 2022 — the exact day of the bear market bottom. Bulls and bears were deadlocked at $352. The very next day buyers took control and the recovery began.🕯️ PatternsInvestopedia StockCharts
16EngulfingA two-candle reversal pattern where a large candle completely engulfs the prior candle's body. Bullish = big green candle after red = buyers took over. Bearish = big red after green.💡 Example: NVDA formed a massive bullish engulfing candle on January 6, 2023 after its 2022 selloff — marking the start of an 800%+ rally to new ATHs. The single candle swallowed the entire prior day's range.🕯️ PatternsInvestopedia StockCharts
17Break of Structure (BOS)Price breaks a significant recent high or low, confirming the trend continues. Bullish BOS = new higher high made. A key entry trigger for trend traders.💡 Example: The S&P 500 breaking above 5,000 in February 2024 was a clear bullish BOS — confirming the recovery from the 2022 lows and giving institutional traders confidence to add to long positions.📐 Price StructureInvestopedia Babypips
18Change of Character (CHoCH)The first sign a trend may be reversing — price breaks opposite to the current trend for the first time. An early warning, not yet confirmation. Watch closely after a CHoCH.💡 Example: In October 2022, the S&P 500 failed to make a new lower low for the first time in months. That CHoCH signaled the potential bottom — smart money started positioning long before the recovery was confirmed.📐 Price StructureBabypips TradingView
19Market StructureThe overall pattern of highs and lows that defines the trend. The foundation of all technical analysis — identify structure before any other indicator.💡 Example: QQQ's 2023 structure was perfectly bullish: Jan low ($265) → Mar low ($296) → May low ($316) → each trough higher than the last. Recognizing this structure early kept traders on the right side all year.📐 Price StructureInvestopedia QQQ Chart
20Order Block (OB)A price zone where institutions placed large orders — often the last bullish candle before a sharp drop, or last bearish candle before a sharp rally. Acts as a magnet for future price.💡 Example: EUR/USD repeatedly returns to the 1.0700–1.0720 area (a major institutional order block) before resuming directional moves. Banks placed billions of orders there; price respects the zone repeatedly.📐 Price StructureBabypips EUR/USD Chart
21Fair Value Gap (FVG)A price imbalance where buying and selling were unequal — price moved so fast that orders weren't filled. Acts like a magnet; price often retraces to "fill" it.💡 Example: NVDA gapped from $455 to $502 on earnings (Aug 2023), leaving an FVG at $455–$470. On the September pullback, price fell to exactly that zone before bouncing — filling the imbalance precisely.📐 Price StructureInvestopedia NVDA Chart
22Liquidity GrabPrice briefly spikes beyond a key level where stop-losses cluster, triggers those stops, then reverses sharply. Institutions "hunt" these stops to fill their large orders.💡 Example: Bitcoin spiked to $69,500 in March 2024 — just above the $69K 2021 ATH — triggering billions in stop-loss orders from short sellers. Within days BTC reversed to $60K. Classic stop-hunt before the real move.📐 Price StructureInvestopedia BTC Price
23Stop Loss (SL)A pre-set price where your trade automatically closes to limit your loss. The single most important risk management tool. Define it before entering the trade — never after.💡 Example: Buy NVDA at $800, ATR-14 = $18. Stop at $800 − (18 × 1.5) = $773. Max loss = $27/share. On 100 shares = $2,700 risk — controlled and defined before the trade begins.🛡️ Risk ManagementInvestopedia SEC Guide
24Take Profit (TP)A pre-set target price where your trade closes to lock in profit. Removes greed and emotion from the exit — you decided the target when you were rational, before emotions could interfere.💡 Example: Buy SPY at $450, stop $440 ($10 risk). Set TP1 at $470 (2:1 R:R) to exit half, TP2 at $480 (3:1 R:R) for the rest. Scale out on the way up — protect gains while letting winners run.🛡️ Risk ManagementInvestopedia Babypips
25Risk/Reward (R:R)The ratio of potential profit to potential loss. 1:3 = risk $100 to potentially gain $300. Professional rule: never trade less than 1:2 R:R. Math wins over time even with a 50% win rate.💡 Example: TSLA: entry $200, stop $190 (−$10 risk), target $230 (+$30 reward) = 1:3 R:R. With 50% win rate over 10 trades: 5 wins × $30 = +$150, minus 5 losses × $10 = −$50 = net +$100 profit.🛡️ Risk ManagementInvestopedia Babypips
26Position SizeHow much capital you allocate to a single trade. Calculated from stop distance and max account risk per trade (typically 1%). Ensures one loss never devastates your account.💡 Example: $50,000 account × 1% = $500 max risk. Stop is $5 from entry. Position = $500 ÷ $5 = 100 shares. That $10,000 position risks only 1% of the account if the stop triggers.🛡️ Risk ManagementInvestopedia Position Calc
27LeverageBorrowed capital from your broker letting you control a larger position than your account balance. Amplifies both gains AND losses — a double-edged sword.💡 Example: Archegos Capital used ~5× leverage on media stocks in 2021. When ViacomCBS fell 50%, Archegos lost $20B+ in days and collapsed — one of history's largest single-firm losses. Leverage without risk management is fatal.💰 Account & MarginInvestopedia Bloomberg
28MarginThe minimum funds required to open and maintain a leveraged trade — a refundable deposit. If the trade moves too far against you, a margin call is triggered.💡 Example: To buy 1 standard lot of EUR/USD ($100,000 notional) with 50:1 leverage, you need $2,000 margin. That $2,000 deposit controls a position 50× its size. Moves of just 2% can wipe out the entire deposit.💰 Account & MarginInvestopedia Babypips
29Margin CallYour broker demands more funds (or force-closes positions) because your account fell below the required minimum. Avoid at all costs — it means losses have reached a critical level.💡 Example: Archegos Capital received simultaneous margin calls from Goldman Sachs, Morgan Stanley, and Credit Suisse in March 2021 — resulting in forced liquidation of $20B+ in a single day and major bank losses.💰 Account & MarginInvestopedia CNBC
30EquityYour real-time account value including unrealized P&L from open trades. Equity fluctuates live; Balance only changes when you close a trade.💡 Example: Account balance = $10,000. Open NVDA trade currently up $1,200 unrealized. Your equity = $11,200 — but this profit is not real until you click "Close." A sudden reversal could erase it.💰 Account & MarginInvestopedia
31BalanceYour account balance counting only closed (realized) trades. Balance only changes when you exit a position. Equity includes open trade P&L; Balance does not.💡 Example: Start: $10,000 balance. Close AAPL trade: +$500. Balance = $10,500. Open NVDA trade with $2,000 unrealized gain. Equity = $12,500 — but Balance stays $10,500 until you exit NVDA.💰 Account & MarginInvestopedia
32DrawdownThe reduction from your account's peak balance. If your account hit $15,000 then fell to $12,000, that is a 20% drawdown. Controlling max drawdown is critical for long-term survival.💡 Example: Warren Buffett's Berkshire Hathaway suffered a ~50% drawdown during 2008 (from $150K to $73K per share). Even the greatest investors face brutal drawdowns — the key is surviving them without panic-selling.🛡️ Risk ManagementInvestopedia BRK-A History
33CompoundingEarning returns on your previous returns. Reinvesting profits generates exponential growth over time — the snowball effect. Time and consistency are the two requirements.💡 Example: Warren Buffett made 20%+ annually for 60 years. $10,000 at 20%/year for 60 years = over $56 million. Most of his wealth was made after age 65 — pure compounding. The earlier you start, the more powerful it becomes.🛡️ Risk ManagementInvestopedia Buffett Letters
34Lot SizeThe standardized unit of trade size. Forex: 1 standard lot = 100,000 units; mini = 10,000; micro = 1,000. Determines your dollar profit/loss per pip.💡 Example: Trading 0.1 lots (10,000 units) of EUR/USD: each pip = $1. A 50-pip move = $50 profit or loss. Trading 1 full lot: each pip = $10, same move = $500. Lot size directly controls your risk exposure.⚙️ Trade MechanicsInvestopedia Babypips
35PipThe smallest standard price increment in forex. Most pairs: 1 pip = 0.0001 (4th decimal). JPY pairs: 1 pip = 0.01 (2nd decimal). On 1 standard lot, 1 pip = $10.💡 Example: EUR/USD moves from 1.0850 to 1.0900 = 50 pips. On 1 standard lot = $500 profit. In the 2015 CHF "black swan," EUR/CHF dropped 1,500+ pips in seconds — many traders lost more than their entire account.⚙️ Trade MechanicsInvestopedia Babypips
36SpreadThe gap between the buy (ask) and sell (bid) price — your broker's built-in transaction fee. Tighter spread = cheaper to trade. Wider spread = more expensive.💡 Example: EUR/USD bid 1.0850 / ask 1.0852 = 2-pip spread. On 1 standard lot you're instantly $20 in the red. USD/ZAR (exotic) may have a 200-pip spread — you need a $140 move just to break even.⚙️ Trade MechanicsInvestopedia Babypips
37SlippageThe difference between your expected fill price and actual fill price. Happens during fast markets, news events, or low-liquidity instruments. Limit orders eliminate slippage.💡 Example: During the January 2015 Swiss Franc flash crash, EUR/CHF traders with stops at 1.1800 were filled as low as 1.0200 — 1,600 pips of slippage. Several major forex brokers went bankrupt from client losses.⚙️ Trade MechanicsInvestopedia WSJ
38Pending OrderAn instruction to enter a trade only when price reaches a specific level. Set it and walk away — triggers automatically when price gets there. No need to watch the screen.💡 Example: NVDA at $850. You identify $820 as key support. Set a buy limit order at $820. Price dips to $820 two days later — you get filled automatically at your desired level without watching the screen all day.📋 OrdersInvestopedia Babypips
39Market OrderBuy or sell immediately at the current best available price. Guaranteed execution, but may fill at a slightly different price (slippage). Best when speed matters more than precision.💡 Example: SPY breaks above the opening range high at 9:35 AM on huge volume. You need in RIGHT NOW before the move accelerates — a market order gets you filled instantly, even if the fill is $0.05 above what you saw.📋 OrdersInvestopedia SEC Guide
40Limit OrderBuy at or below a target price (buy limit) or sell at or above a target price (sell limit). No slippage — you get the price you want or no fill at all.💡 Example: TSLA approaching $250 resistance. Set a sell limit at $249.90 to exit near the top. If price reaches $249.90 you're sold at exactly that price. If it reverses at $245, your order never triggers — protecting you from overreaching.📋 OrdersInvestopedia SEC Guide
41Stop OrderTriggers when price hits a level, then executes as a market order. Used to enter breakouts or exit losing positions automatically. Subject to slippage once triggered.💡 Example: QQQ consolidating at $450. Set a buy stop at $452 — enters automatically if and only if price breaks above, confirming the breakout. Without this, you would need to watch the screen all day waiting for the trigger.📋 OrdersInvestopedia SEC Guide
42Trailing StopA dynamic stop-loss that automatically follows price in your favor. It locks in more profit as price moves your way, but never moves against you.💡 Example: Buy NVDA at $800, set $30 trailing stop. NVDA rallies to $950 — stop auto-adjusts to $920. NVDA drops from $950 to $918 → you exit at $920, locking in $120/share profit without ever manually moving the stop.📋 OrdersInvestopedia NVDA Chart
43TimeframeThe time period each candlestick represents: 1-min, 5-min, 1-hr, 4-hr, daily, weekly. Higher timeframes = bigger picture, fewer false signals. Always trade in the direction of the higher timeframe.💡 Example: The same SPY chart tells different stories: 5-min shows volatile noise; daily shows clear pullbacks in an uptrend; weekly shows the major multi-year bull market. Align timeframes before entering any trade.⚙️ Trade MechanicsInvestopedia TradingView
44ScalpingA high-frequency style capturing many tiny profits per day — seconds to minutes per trade. Requires fast broker, tight spreads, disciplined entries and exits.💡 Example: A EUR/USD scalper takes 20 trades/day, targeting 3–5 pips each, holding 30–90 seconds. Net: 80 pips/day × $10/pip on a standard lot = $800. Requires near-perfect execution and psychological discipline.⏱️ Trading StyleInvestopedia Babypips
45Swing TradingHolding trades for days to weeks to capture one full price "swing" in a trend. Less intensive than day trading. Ideal if you can't watch screens all day.💡 Example: Buying NVDA on a 3-day pullback to the 21 EMA at $850 (from $920 high), targeting $970 over 2–3 weeks — a 14% swing. Checking charts only morning and evening is sufficient.⏱️ Trading StyleInvestopedia NVDA Chart
46Day TradingOpening and closing all trades within the same day — no overnight positions. Avoids overnight risk but demands full-day attention and disciplined exits before close.💡 Example: Buying TSLA at 9:45 AM on an Opening Range Breakout at $220, targeting $228 by noon, and closing by 3:45 PM.
